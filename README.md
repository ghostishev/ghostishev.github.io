# Портфоліо — Олена Чумаченко

Статичний односторінковий сайт (HTML + CSS + JS, без збірки та залежностей),
зверстаний за слайдами презентації-портфоліо.

```
index.html    розмітка та весь текст
styles.css    палітра, типографіка, сітки, анімації
script.js     індикатор прокрутки, шапка, поява блоків, паралакс
images/       фото та сертифікати (див. images/README.md)
.nojekyll     GitHub Pages віддає файли як є, без Jekyll
```

## Що всередині

- **Перший екран** — велике слово `ПОРТФОЛІО`, літери «ФО» контурні, щоб фото
  на прозорому фоні лягало поверх них, як на слайді.
- **Секції** `Про мене → Освіта → Досвід і ніші → Контакти` з нумерацією
  `[ 01 ]`, як у презентації.
- Шапка з навігацією з'являється при прокрутці, підсвічує активну секцію.
- Блоки плавно з'являються (`IntersectionObserver`), картки ніш мають
  hover-заливку.
- Адаптив від 320 px; повага до `prefers-reduced-motion`.

## Зображення

Файли ще не додані — покладіть їх у `images/` за іменами з
[images/README.md](images/README.md). Поки файлу немає, блок ховається або
показує заглушку, тож сторінка не ламається.

## Локальний перегляд

```bash
python3 -m http.server 8000
```

Далі відкрити http://localhost:8000

## Публікація на GitHub Pages

Для адреси `https://<username>.github.io` репозиторій має називатися саме
`<username>.github.io`. Далі в **Settings → Pages** вибрати
*Deploy from a branch* → `main` / `root`.

## Що варто оновити перед публікацією

- Telegram-нік у трьох місцях `index.html` (шапка, картка CTA, секція контактів),
  якщо він відрізняється.
- `og:image` в `<head>` — після додавання `images/hero.png`.
