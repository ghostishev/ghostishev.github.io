## `source/` — оригінали

Тут лежать вихідні файли, як їх було надано:

- `cert-blog.pdf`, `cert-shooting.pdf`, `cert-smm.pdf` — сертифікати були
  у PDF (з розширенням `.jpg`), тому браузер їх не показував; для сторінки
  вони растеризовані у JPEG по 1600 px більшою стороною.
- `cert-video.pdf` — сертифікат «Мобільна відеозйомка», так само PDF.
- `cert-nisha.png`, `portrait.png`, `hero.png` — вихідні PNG.
- `contact-figure.png` — вихідна постать для секції «Контакти»
  (566×1042; на сторінці — зменшена до 489×900).
- `slide-11-contact.jpg` — фінальний слайд презентації «Готова до
  співпраці», з якого взято постать для `contact-figure.png`. Сам слайд
  на сторінці не використовується — він тут як орієнтир композиції.

Разом оригінали важать ~9 МБ, версії для сторінки — ~1,9 МБ.

## Якщо треба перегенерувати

```bash
sips --resampleHeightWidthMax 1600 -s format jpeg -s formatOptions 82 source/cert-smm.pdf --out cert-smm.jpg
```
