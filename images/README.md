# Зображення

Поклади сюди файли з такими іменами — сторінка підхопить їх автоматично.
Поки файлу немає, блок акуратно ховається (або показує заглушку), тож сайт
не ламається.

| Файл | Що це | Рекомендації |
|---|---|---|
| `hero.png` | Фото на весь зріст для першого екрана | **PNG з прозорим фоном** (вирізане фото), висота ~1400 px |
| `portrait.jpg` | Портрет для секції «Про мене» | вертикальний, співвідношення 3:4, ~900×1200 px |
| `cert-smm.jpg` | Сертифікат «SMM-менеджмент» | горизонтальний, ~1000 px по ширині |
| `cert-shooting.jpg` | Сертифікат «Зйомка контенту для бізнесу» | те саме |
| `cert-nisha.jpg` | Сертифікат «SMM-дизайн у Figma» (nisha.space) | те саме |
| `cert-blog.jpg` | Сертифікат «Книжковий блог» (Litosvita) | те саме |

Для `hero.png` фон обов'язково прозорий — саме завдяки цьому літери «ФО»
у слові ПОРТФОЛІО лягають поверх фото контуром, як на слайді.
