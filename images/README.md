# Зображення

Файли, які використовує сторінка (усі вже на місці):

| Файл | Що це | Формат |
|---|---|---|
| `hero.png` | Постать на весь зріст для першого екрана | PNG з прозорим фоном, 640×1403 |
| `portrait.jpg` | Портрет для секції «Про мене» | JPEG, 978×1500 |
| `cert-smm.jpg` | Сертифікат «SMM-менеджмент», Центр Едукації | JPEG, 1600×1128 |
| `cert-shooting.jpg` | Сертифікат «Зйомка контенту для бізнесу» | JPEG, 1600×1128 |
| `cert-nisha.jpg` | Сертифікат «SMM-дизайн у Figma», nisha.space | JPEG, 1600×1152 |
| `cert-blog.jpg` | Сертифікат «Книжковий блог», Litosvita | JPEG, 1131×1600 |

Прозорий фон у `hero.png` — обовʼязковий: саме завдяки йому літери «ФО»
у слові ПОРТФОЛІО лягають поверх фото контуром, як на слайді.

## `source/` — оригінали

Тут лежать вихідні файли, як їх було надано:

- `cert-blog.pdf`, `cert-shooting.pdf`, `cert-smm.pdf` — сертифікати були
  у PDF (з розширенням `.jpg`), тому браузер їх не показував; для сторінки
  вони растеризовані у JPEG по 1600 px більшою стороною.
- `cert-nisha.png`, `portrait.png`, `hero.png` — вихідні PNG.

Разом оригінали важать ~9 МБ, версії для сторінки — ~1,9 МБ.

## Якщо треба перегенерувати

```bash
sips --resampleHeightWidthMax 1600 -s format jpeg -s formatOptions 82 source/cert-smm.pdf --out cert-smm.jpg
```
